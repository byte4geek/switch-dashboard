Dashboard REST API Documentation

A reference guide to the HTTP endpoints built into the Switch Dashboard. All programmatic access runs through the local Flask server layer on port 8080.

Retrieves a full, live status report of all managed switches. This includes system-level parameters (Uptime, Firmware, MAC) and individual port configuration metrics.

    "error": null,

      {
        "port": "1",

        "speed": "1000M",

GET /api/history Bandwidth Graph History Data

Retrieves historical data arrays for populating bandwidth charts. Ideal for mapping out transmission graphs over time.

Query Parameters
Parameter Type Status Description
ip string Required Target switch IP.
port string Required Target switch port number.
range string Optional History scale. Options: live (default, bits/s), 1h (Bytes/s), or 24h (Bytes/s).
Response JSON 
{
  "timestamps": [1716280000, 1716280010, 1716280020],
  "tx": [125000, 142000, 138000],
  "rx": [4500000, 4820000, 4710000]
}
POST /api/notes Save Custom Port Note/Label

Appends a persistent description or note to a specific switch interface. Comments are stored on the server's local disk inside notes.json.

Request Payload (JSON)
Key Type Status Description
key string Required Identifier in ip_address:port_num format (e.g. "192.168.1.100:9").
val string Required Text content of the note. Pass an empty string "" to delete notes.
Request Payload 
{
  "key": "192.168.1.100:9",
  "val": "Backbone Server Rack Uplink"
}
GET /api/settings Retrieve Global System Settings

Retrieves global dashboard settings currently stored in the backend.

Response JSON 
{
  "refresh": 10
}
POST /api/settings Update Global System Settings

Updates global settings in the dashboard environment, immediately adjusting background cycles.

Request Payload (JSON)
Key Type Status Description
refresh integer Required Polling interval in seconds. Minimum value is 5.
Request Payload 
{
  "refresh": 15
}
POST /api/reset Reset Counters & Charts

Purges temporary memory caching logs and charts, forcing a re-alignment of base traffic stats.

Response JSON 
{
  "status": "ok"
}
POST /api/switches/<ip>/backup Trigger Switch Configuration Backup

Logs into the switch at the given IP address, triggers an on-demand download of the binary configuration file from the switch CGI interface, and saves it in the server's local file archive.

Path Parameters
Parameter Type Status Description
ip string Required The IP address of the target switch.
Response JSON 
{
  "filename": "switch_cfg_192-168-1-100_20260521_1519.bin",
  "size": 2708,
  "status": "ok",
  "timestamp": "20260521_1519"
}
POST /api/switches/<ip>/reboot Trigger Switch Reboot

Triggers an on-demand reboot of the target switch. The device will perform a soft reset immediately, which will temporarily disrupt connectivity on that switch.

Path Parameters
Parameter Type Status Description
ip string Required The IP address of the target switch.
Response JSON 
{
  "message": "Reboot command sent successfully",
  "status": "ok"
}
GET /api/backups List Configuration Backups

Scans the server backup directory and returns a sorted list of all archived configuration files including switch IP, timestamp, human-readable file size, and exact filename metadata.

Response JSON 
[
  {
    "datetime": "2026-05-21 15:19",
    "filename": "switch_cfg_192-168-1-100_20260521_1519.bin",
    "ip": "192.168.1.100",
    "mtime": 1779376740.0,
    "size": 2708,
    "size_str": "2.6 KB"
  }
]
GET /api/backups/<filename>/download Download Backup File

Downloads a specific archived configuration backup file from the server's local storage. This endpoint includes directory traversal protection to block unauthorized path accesses.

Path Parameters
Parameter Type Status Description
filename string Required The target backup filename, e.g. switch_cfg_192-168-1-100_20260521_1519.bin.
Response Format 
Binary Stream (application/octet-stream attachment)
DELETE /api/backups/<filename> Delete Backup File

Permanently purges a specific configuration backup file from the server storage disk. Includes strict path verification to prevent directory traversal exploits.

Path Parameters
Parameter Type Status Description
filename string Required The target backup filename to delete.
Response JSON 
{
  "status": "ok"
}
POST /api/vendors/update_oui Update IEEE OUI Databases

Triggers an on-demand download of the official IEEE OUI registration databases (oui.txt and oui36.txt) to resolve MAC addresses to manufacturers. Requires internet connection to IEEE servers. Note that IEEE limits queries to one download per day.

Response JSON 
{
  "message": "IEEE OUI databases successfully updated.",
  "status": "ok"
}

POST /api/scanner/hosts/<mac>/known Update Known Host Status

Toggles the "Known Device" flag for a scanned host identified by its MAC address (or IP address fallback).

Path Parameters
Parameter Type Status Description
mac string Required Target client's MAC address (or IP address).
Request Payload (JSON)
Key Type Status Description
known integer Required Set to 1 for known, or 0 for unknown.
Response JSON 
{
  "success": true
}
POST /api/scanner/hosts/<mac>/update Rename Host or Update Note

Modifies the custom hostname or descriptive note for a scanned client device in the configurations.

Path Parameters
Parameter Type Status Description
mac string Required Target client's MAC address (or IP address).
Request Payload (JSON)
Key Type Status Description
field string Required Target field to edit. Must be either "hostname" or "note".
value string Required The new text value. Note that hostname mappings are updated accordingly.
Response JSON 
{
  "success": true
}
DELETE /api/scanner/hosts/<mac> Remove Scanned Host

Permanently removes a dynamically scanned host from the active dashboard database. If the host is mapped to a switch port, its scanner active state is disabled.

Path Parameters
Parameter Type Status Description
mac string Required Target client's MAC address (or IP address).
Response JSON 
{
  "success": true
}
GET /api/scanner/history Get Connection Timelines

Retrieves all network status transitions (online/offline transitions) grouped by host, extracted from the SQLite connection history database.

Response JSON 
{
  "192.168.1.15": {
    "hostname": "SmartTV",
    "events": [
      {
        "status": 1,
        "event_time": "2026-06-11T10:00:00Z"
      },
      {
        "status": 0,
        "event_time": "2026-06-11T12:00:00Z"
      }
    ]
  }
}
DELETE /api/scanner/history/<ip> Delete Host Timeline History

Permanently purges connection history logs for a specific host from the SQLite database.

Path Parameters
Parameter Type Status Description
ip string Required The IP address (or MAC address) of the client.
Response JSON 
{
  "success": true
}
DELETE /api/scanner/history/all Purge All Scanner History

Wipes out the entire connection timeline transition log database for all hosts. This action is irreversible.

Response JSON 
{
  "success": true
}

Deletes a client record binding (by MAC address) from the active configuration registry.

Request Payload (JSON)

Response JSON

GET /api/templates List Config Templates

Returns a list of device-specific scraper settings templates stored in the templates directory.

[
  "horaco_8port.yaml",

GET /api/logs Get System Logs

Reads the active backend system logs and returns the tail output of the execution thread.

Query Parameters
Parameter Type Status Description
lines integer Optional Max lines to retrieve (default 100).
Response JSON 
[
  "2026-06-11 14:02:11 - scraper - INFO - Starting background task",
  "2026-06-11 14:02:30 - app - INFO - API call /api/switches"
]
POST /api/logs/level Set Logging Level

Updates backend logger verbosity levels dynamically without restarting the application thread.

Request Payload (JSON)
Key Type Status Description
level string Required Active logger filter: DEBUG, INFO, WARN, ERROR, or NONE.
Response JSON 
{
  "status": "ok",
  "level": "DEBUG"
}
POST /api/logs/clear Truncate Logs

Wipes the contents of the central execution log file stored on backend disk storage.

Response JSON 
{
  "status": "ok"
}
GET /api/logs/download Download Logs File

Downloads the complete text log file from the server storage.

Response Format 
Plain Text File stream (attachment)
